NEON.DOC на Mac (Apple Silicon M1–M5) — полная установка
=========================================================

1. Распакуй NEON.DOC-mac.zip (двойной клик). Появятся папка NEON.DOC и файл «Установить NEON.DOC».
   Перенеси ОБА в удобное место, например в «Документы» (не запускай из «Загрузок»).

2. Двойной клик по «Установить NEON.DOC».
   Если macOS пишет «не удаётся проверить разработчика»:
     • правый клик по файлу → «Открыть» → «Открыть»;
     • или «Системные настройки → Конфиденциальность и безопасность» → внизу «Всё равно открыть»;
     • или Терминал: напечатай  bash  (с пробелом), перетащи файл в окно, Enter.

3. Установщик сам скачает и настроит ВСЁ:
   ✓ Python 3.12 и все библиотеки (без Homebrew и пароля администратора)
   ✓ Ollama — движок языковых моделей
   ✓ языковую модель под память Mac:  48 ГБ+ → qwen3.6:27b (как на ПК),
     32–47 ГБ → qwen3.6:35b-a3b,  меньше → qwen3.5:9b
   ✓ Whisper large-v3-turbo для расшифровки на чипе Apple (MLX)
   ✓ модели разделения речи по участникам
   ✓ LibreOffice для PDF — только если нет Microsoft Word
   ✓ приложение NEON.DOC в Launchpad, Spotlight и Dock
   В конце — самопроверка всех частей. Займёт 20–60 минут, Mac не будет засыпать.
   Нужно ~25–30 ГБ свободного места (для Mac с 32+ ГБ памяти).

4. Дальше запуск — значок NEON.DOC в Dock или Launchpad.

Отличия от ПК
- Расшифровка — на видеочипе Apple. Процент выполнения не показывается: текст появляется целиком в конце.
- PDF — через Word для Mac или LibreOffice.
- Первый раз macOS спросит доступ к микрофону (диктовка) и к управлению Word (PDF) — «Разрешить».
- «Показать в папке» открывает Finder.

Обновление и починка — снова «Установить NEON.DOC»: докачает недостающее, данные не трогает.
Если что-то не так — пришли install_mac.log или neondoc.log из папки NEON.DOC.
